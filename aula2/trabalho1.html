Introdução às principais tags HTML

  • "h1..6" cria cabeçalhos, com a fonte grande
    por padrão, existe apenas um "h1" por pagina, mas não é obrigatório

  • "p" cria um parágrafo de texto
    enquanto o "br" força uma quebra de linha
    "b" deixa o texto em negrito, e o "i" deixa o texto em itálico

  • "hr" cria uma linha horizontal, usada para separar conteúdos

  • "a" cria um link

    • o atributo "href" define o destino do link

    • o atributo "target" define onde o link será aberto

      • "_self" abre na mesma aba (padrão)

      • "_blank" abre em nova aba

  • "img" insere uma imagem

    • o atributo "src" define a fonte da imagem (local ou URL)

    • o atributo "alt" define um texto alternativo para a imagem, caso ela não possa ser exibida

  • "ul" cria uma lista não ordenada (com marcadores)
    "ol" cria uma lista ordenada (numerada)
    "li" define um item de lista, usado dentro de "ul" ou "ol"

  • "table" cria uma tabela

    • "tr" define uma linha da tabela

    • "th" define uma célula de cabeçalho (geralmente em negrito e centralizada)

    • "td" define uma célula de dados (conteúdo da tabela)

  • "div" cria uma divisão ou seção na pagina, usada para agrupar outros elementos e aplicar estilos CSS
